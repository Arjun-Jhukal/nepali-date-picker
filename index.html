Bikram Sambat Date Picker

The accurate Nepali date picker.

Vanilla JS, zero runtime dependencies. BS ↔ AD conversion backed by official GoN calendar data — not algorithmic guesswork.

npm install nepali-bs-date-picker

~8 KB gzipped BS 2082–2090 EN + नेपाली MIT

Documentation

Getting started

Add the CSS, load the script, and attach a picker to any input element.

Via CDN (quickest)

<link rel="stylesheet" href="https://unpkg.com/nepali-bs-date-picker/dist/nepali-date-picker.min.css">
<script src="https://unpkg.com/nepali-bs-date-picker/dist/nepali-date-picker.iife.min.js"></script>

<input type="text" id="dob" placeholder="YYYY-MM-DD">
<script>
  NepaliDatePicker.attach('#dob');
</script>

Via npm (ESM)

import 'nepali-bs-date-picker/css';
import { NepaliDatePicker } from 'nepali-bs-date-picker';

NepaliDatePicker.attach('#dob', {
    language: 'np',
    onChange: (date) => console.log(date.format('YYYY-MM-DD')),
});

NepaliDate

const { NepaliDate } = NepaliDatePicker;

const d = new NepaliDate(2082, 1, 15);   // year, month (1-12), day
const today = NepaliDate.today();
const fromAD = NepaliDate.fromAD(new Date());

d.getYear()    // 2082
d.getMonth()   // 1
d.getDate()    // 15
d.getDay()     // 0–6 (day of week)
d.toAD()       // JS Date

d.format('MMMM DD, YYYY')           // 'Baisakh 15, 2082'
d.format('MMMM DD, YYYY', 'np')     // 'बैशाख १५, २०८२'
d.isBefore(other)
d.isAfter(other)
d.isSame(other)
d.diff(other, 'day')    // signed number of days

Auto-init via data attributes

No JavaScript needed. Add data-nepali-datepicker to any input and it initializes automatically on page load.

<input type="text"
       data-nepali-datepicker
       data-language="np"
       data-format="YYYY-MM-DD"
       data-theme="light">

Examples

Live demos

Every demo below is powered by the actual library loaded on this page.

Basic

Attach to an input by ID. The onChange callback receives a NepaliDate object.

NepaliDatePicker.attach('#date-basic', {
    onChange: (date) => {
        console.log(date.format('MMMM DD, YYYY'));
    },
});

Nepali language + Devanagari numerals

Pass language: 'np' and useNepaliNumerals: true for a fully Nepali UI.

NepaliDatePicker.attach('#date-np', {
    language: 'np',
    useNepaliNumerals: true,
    onChange: (date) => {
        console.log(date.format('MMMM DD, YYYY', 'np'));
    },
});

Date range constraints

Dates outside 2083-01-01 to 2083-06-30 are disabled and cannot be selected.

NepaliDatePicker.attach('#date-range', {
    minDate: new NepaliDatePicker.NepaliDate(2083, 1, 1),
    maxDate: new NepaliDatePicker.NepaliDate(2083, 6, 30),
    onChange: (date) => console.log(date.format('YYYY-MM-DD')),
});

Date range — two pickers

Pick a start and end date. The result shows how many days apart they are.

const start = NepaliDatePicker.attach('#start');
const end   = NepaliDatePicker.attach('#end');

function onAnyChange() {
    const a = start.getValue();
    const b = end.getValue();
    if (a && b) console.log(Math.abs(a.diff(b, 'day')) + ' days apart');
}
start.setOptions({ onChange: onAnyChange });
end.setOptions({ onChange: onAnyChange });

Programmatic control

Use the returned Picker instance to control the picker from code.

const picker = NepaliDatePicker.attach('#date-prog');

picker.setValue(NepaliDatePicker.NepaliDate.today());
picker.getValue();   // NepaliDate | null
picker.clear();
picker.open();
picker.close();

AD mode

The calendar shows BS dates but writes the AD equivalent into the input — useful for backend forms that expect AD.

NepaliDatePicker.attach('#date-ad', {
    mode: 'ad',
    onChange: (date) => {
        // date is a NepaliDate; input.value holds the AD string
        console.log('BS:', date.format('YYYY-MM-DD'));
    },
});

Specific disabled dates

Ashadh 10, 15, and 20 of 2083 cannot be selected.

const { NepaliDate } = NepaliDatePicker;
NepaliDatePicker.attach('#date-disabled', {
    defaultDate: new NepaliDate(2083, 3, 1),
    disabledDates: [
        new NepaliDate(2083, 3, 10),
        new NepaliDate(2083, 3, 15),
        new NepaliDate(2083, 3, 20),
    ],
});

Dark theme

Pass theme: 'dark'. Include the dark CSS file for the dark variant.

<!-- add the dark CSS alongside the base CSS -->
<link rel="stylesheet" href="nepali-date-picker.dark.min.css">

NepaliDatePicker.attach('#date-dark', { theme: 'dark' });
