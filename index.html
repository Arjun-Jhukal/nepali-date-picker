Nepali Date Picker & Range Picker 2026

A vanilla JavaScript Nepali (Bikram Sambat) date picker and Nepali date range picker. Zero dependencies · BS ↔ AD conversion · 2082–2100 calendar data · ~11 KB gzipped · Works in plain HTML, WordPress and any framework.

Most existing Nepali date pickers on npm have conversion bugs because they algorithmically derive month lengths. Real Bikram Sambat months are astronomically determined and published yearly — they cannot be calculated. This nepali date picker uses manually verified calendar data for every year from 2082 to 2100, so BS ↔ AD conversion is always correct. The library ships three bundles so you only load what you need:

  • nepali-date-picker.all.min.js — full bundle (popover + inline + range picker)
  • nepali-date-picker.min.js — just the popover datepicker
  • nepali-date-range-picker.min.js — inline calendar with itinerary / availability range mode (~7 KB gzipped)

Basic attach by ID

Click the input to open the picker.
NepaliDatePicker.attach('#date-basic', {
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'));
    },
});

Nepali language + Devanagari numerals

Click the input to open the picker.
NepaliDatePicker.attach('#date-np', {
    language: 'np',
    useNepaliNumerals: true,
    onChange: (date) => {
        console.log(date.format('MMMM DD, YYYY', 'np'));
        console.log('AD:', date.toAD().toLocaleDateString());
    },
});

Min / Max date constraints

Only 2083-01-01 through 2083-06-30 are selectable.

Dates outside the range will be disabled.
NepaliDatePicker.attach('#date-range', {
    minDate: new NepaliDatePicker.NepaliDate(2083, 1, 1),
    maxDate: new NepaliDatePicker.NepaliDate(2083, 6, 30),
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'));
    },
});

Saturday weekend · stay open after select

Saturdays are highlighted. Picker stays open on selection.
NepaliDatePicker.attach('#date-config', {
    weekendDays: [6],       // Saturday only (0=Sun … 6=Sat)
    closeOnSelect: false,   // keep popover open
    firstDayOfWeek: 0,
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'), date.format('dddd'));
    },
});

Multiple pickers — opening one closes the other

Select both dates to see the difference.
const start = NepaliDatePicker.attach('#start');
const end   = NepaliDatePicker.attach('#end');

// date.diff(other, 'day') returns signed day count
function onAnyChange() {
    const a = start.getValue();
    const b = end.getValue();
    if (a && b) console.log(Math.abs(a.diff(b, 'day')) + ' days apart');
}
start.setOptions({ onChange: onAnyChange });
end.setOptions({ onChange: onAnyChange });

Programmatic control

Use the buttons above to control the picker.
const picker = NepaliDatePicker.attach('#date-prog');

// Set a specific date
picker.setValue(new NepaliDatePicker.NepaliDate(2083, 4, 15));

// Set to today
picker.setValue(NepaliDatePicker.NepaliDate.today());

// Read the current value
const date = picker.getValue(); // NepaliDate | null

// Clear
picker.clear();

// Open / close programmatically
picker.open();
picker.close();

AD mode — stores AD date in input

The input value will be in AD format.
NepaliDatePicker.attach('#date-ad', {
    mode: 'ad',   // input value written as YYYY-MM-DD AD
    onChange: (date) => {
        // date is still a NepaliDate for display
        // but input.value contains the AD string
        console.log('BS:', date.format('YYYY-MM-DD'));
        console.log('AD input value:', input.value);
    },
});

Disabled specific dates disabledDates

Ashadh 10, 15, and 20 of 2083 cannot be selected.

Specific dates are greyed out and unselectable.
const { NepaliDate } = NepaliDatePicker;

NepaliDatePicker.attach('#date-disabled', {
    defaultDate: new NepaliDate(2083, 3, 1),
    disabledDates: [
        new NepaliDate(2083, 3, 10),
        new NepaliDate(2083, 3, 15),
        new NepaliDate(2083, 3, 20),
    ],
});

Inline calendar — single month attachInline

Embedded directly in the page. Each cell shows the BS date (large) and the corresponding AD date (small). Covers full available width.

Click a date to select it. 
const cal = NepaliDatePicker.attachInline('#cal-single', {
    months: 1,
    showAdDate: true,
    weekendDays: [6],        // Saturday highlighted
    onChange: (date) => {
        console.log('BS:', date.format('YYYY-MM-DD'));
        console.log('AD:', date.toAD().toLocaleDateString());
    },
});

Availability calendar — range selection selectionMode: 'range'

Trek / booking use-case. Click any departure date to auto-highlight a 7-day itinerary. The dual-month view lets you see ranges that cross a month boundary. Switch to free-range mode to pick custom start and end dates. Click the month/year title to jump directly to any month.

Click a departure date to select the itinerary. 
const cal = NepaliDatePicker.attachInline('#cal-range', {
    months: 2,
    selectionMode: 'range',
    rangeLength: 7,       // auto-select 7 days on click
    showAdDate: true,
    weekendDays: [6],
    onRangeChange: (start, end) => {
        if (start && end) {
            console.log('From:', start.format('YYYY-MM-DD'));
            console.log('To:  ', end.format('YYYY-MM-DD'));
            console.log('Days:', start.diff(end, 'day') + 1);
        }
    },
});

// Switch to free range (user picks custom start + end):
cal.setOptions({ rangeLength: null });

// Set range programmatically:
const today = NepaliDatePicker.NepaliDate.today();
cal.setRange(today, today.add(6, 'day'));
