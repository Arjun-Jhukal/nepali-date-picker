Nepali Date Picker

Vanilla JS · Zero dependencies · BS ↔ AD conversion · ~8 KB gzipped

Basic attach by ID

Click the input to open the picker.
NepaliDatePicker.attach('#date-basic', {
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'));
    },
});

Nepali language + Devanagari numerals

Click the input to open the picker.
NepaliDatePicker.attach('#date-np', {
    language: 'np',
    useNepaliNumerals: true,
    onChange: (date) => {
        console.log(date.format('MMMM DD, YYYY', 'np'));
        console.log('AD:', date.toAD().toLocaleDateString());
    },
});

Min / Max date constraints

Only 2083-01-01 through 2083-06-30 are selectable.

Dates outside the range will be disabled.
NepaliDatePicker.attach('#date-range', {
    minDate: new NepaliDatePicker.NepaliDate(2083, 1, 1),
    maxDate: new NepaliDatePicker.NepaliDate(2083, 6, 30),
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'));
    },
});

Saturday weekend · stay open after select

Saturdays are highlighted. Picker stays open on selection.
NepaliDatePicker.attach('#date-config', {
    weekendDays: [6],       // Saturday only (0=Sun … 6=Sat)
    closeOnSelect: false,   // keep popover open
    firstDayOfWeek: 0,
    onChange: (date) => {
        console.log(date.format('YYYY-MM-DD'), date.format('dddd'));
    },
});

Multiple pickers — opening one closes the other

Select both dates to see the difference.
const start = NepaliDatePicker.attach('#start');
const end   = NepaliDatePicker.attach('#end');

// date.diff(other, 'day') returns signed day count
function onAnyChange() {
    const a = start.getValue();
    const b = end.getValue();
    if (a && b) console.log(Math.abs(a.diff(b, 'day')) + ' days apart');
}
start.setOptions({ onChange: onAnyChange });
end.setOptions({ onChange: onAnyChange });

Dark theme theme: 'dark'

The popover uses the dark theme.
NepaliDatePicker.attach('#date-dark', {
    theme: 'dark',
});

Auto-init data-nepali-datepicker

No JavaScript needed — just add the attribute.

<!-- No JS required, options via data-* attributes -->
<input type="text"
       data-nepali-datepicker
       data-language="en"
       data-format="YYYY-MM-DD"
       data-theme="light">

Programmatic control

Use the buttons above to control the picker.
const picker = NepaliDatePicker.attach('#date-prog');

// Set a specific date
picker.setValue(new NepaliDatePicker.NepaliDate(2083, 4, 15));

// Set to today
picker.setValue(NepaliDatePicker.NepaliDate.today());

// Read the current value
const date = picker.getValue(); // NepaliDate | null

// Clear
picker.clear();

// Open / close programmatically
picker.open();
picker.close();

AD mode — stores AD date in input

The input value will be in AD format.
NepaliDatePicker.attach('#date-ad', {
    mode: 'ad',   // input value written as YYYY-MM-DD AD
    onChange: (date) => {
        // date is still a NepaliDate for display
        // but input.value contains the AD string
        console.log('BS:', date.format('YYYY-MM-DD'));
        console.log('AD input value:', input.value);
    },
});

Disabled specific dates disabledDates

Ashadh 10, 15, and 20 of 2083 cannot be selected.

Specific dates are greyed out and unselectable.
const { NepaliDate } = NepaliDatePicker;

NepaliDatePicker.attach('#date-disabled', {
    defaultDate: new NepaliDate(2083, 3, 1),
    disabledDates: [
        new NepaliDate(2083, 3, 10),
        new NepaliDate(2083, 3, 15),
        new NepaliDate(2083, 3, 20),
    ],
});
